# agartha landing

Marketing site. Next.js 16 + Tailwind v4 + framer-motion + Lenis.

```bash
bun install
bun run dev
```

## Placeholder assets

`public/hero.mp4` and `public/slides/*` are gitignored. They are stand-in media
from the design reference and are not redistributed here. The hero and the skill
slider will render without them (the video simply shows the background colour);
drop in Minecraft capture footage at those paths to restore them.

## Where the numbers come from

Every figure on the page traces to `docs/MEASUREMENTS.md` in this repo. If a
number here is not in that file, it should be labelled as a target rather than
stated as a result.
